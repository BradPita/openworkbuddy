OpenWorkBuddy 授权码核验

粘贴授权码，在本机浏览器里验真伪。不联网、不上传，码不会离开这台电脑。

对照你们的情况（可不填）

这一页怎么验的

  1. 授权码分三段：OWB1.〈内容〉.〈签名〉。签名用 Ed25519 算法，签的是前两段连同中间的点。
  2. 私钥只在作者手里，只有作者签得出能验过的码。公钥公开在官方仓库的 src/domains/account/license.js 里，本页只带公钥，没有签发功能。
  3. 内容里改一个字、签名少复制一截、换一把钥匙签，都验不过。

本页用来验签的公钥：

请自己核对这把公钥：打开官方仓库 github.com/CatCatUncle/openworkbuddy 里的 src/domains/account/license.js，找到 PUBLIC_KEYS 那一行，逐字比对。作者换钥匙时只会往里追加，旧码照样有效。

验过了说明什么，不说明什么

说明：这串码是作者的私钥签出来的，里面的内容一个字没改过。

不说明：

  • 码是不是签给你们的。要看「授权给」是不是你们单位的全称。
  • 范围、席位、到期日够不够你们用。逐项对照你们的实际用法。
  • 码的来路。授权码可以离线复制，拿到别人的码不等于你们有授权。

拿不准就发邮件找作者核实。联系方式以官方仓库 COMMERCIAL-LICENSE.md 写的为准。

另一种核验办法：命令行

装好 Node.js，克隆官方仓库，在仓库目录里运行下面这行。它用的是仓库自带的 src/domains/account/license.js，和本页互不依赖。

node scripts/issue-license.js verify "OWB1.……"

本页离线运行：没有外部脚本，安全策略禁止任何联网请求，也不保存你粘贴的授权码。可以断网后再打开。

验签规则与官方仓库 src/domains/account/license.js 的 verify() 一致（对照版本 80da093）。到期按你这台电脑的本地日期算，到期日当天仍有效。
