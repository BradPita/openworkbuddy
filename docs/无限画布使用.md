# 无限画布

从左侧「无限画布」进入。顶部选择项目和画布，文件与生成结果保存在对应项目里。

## 从一张图开始

1. 点工具栏「+」→「参考图」。新卡出现在当前视野内，光标直接进入图片提示词。
2. 写清主体、场景和希望改变的内容，再点卡片上的生成按钮。空内容不会发起生成；新卡没有需要先删除的示例文案。
3. 有参考素材时，从「打开素材」添加，或把本机图片拖入画布。从素材卡右侧的连接点拖向生成卡，把它接成上游。
4. 生成结果留在卡上，可以双击图片放大或点预览图标查看。型号、素材和高级参数在卡头的设置里调整。

视频和配音也能在卡上直接输入。镜头卡区分首帧提示词、运镜和台词；视频生成仍需满足所选模型的素材要求。

### 多张参考图一起使用

`Shift`+拖拽框选素材，或 `Shift`/`⌘`/`Ctrl`+点击加选。在多选工具条的「作为参考图…」中选择目标卡，或选「新建图片节点」。连接后直接填写新画面的提示词，不会自动开始生成。

每次最多使用 4 张不同的参考图。超出数量、素材不可用、已有重复连接或会形成循环时，会说明原因并保留原画布。

### 保留参考再做一个方案

右键卡片 →「复制节点」，或选中后按 `⌘D` / `Ctrl+D`。可以复制单张或一组选中的卡。

- 提示词、模型和上游参考关系一起保留。
- 整组复制时，组内连线改连新卡，组外的上游素材仍可复用。
- 新镜头取得新的镜头号，不绑定原镜头的分镜表记录。
- 待收取的生成任务和原节点的生成回执不会复制，避免同一任务被重复收取。

## 移动、查找和整理

| 操作 | 方法 |
| --- | --- |
| 平移 | 拖动画布空白处；触控板双指滑动 |
| 缩放 | 触控板捏合、鼠标按行滚轮，或按住 `⌘`/`Ctrl` 滚动；以光标为中心 |
| 多选 | `Shift`+拖拽；`Shift`/`⌘`/`Ctrl`+点击加选、减选 |
| 全选 | `⌘A` / `Ctrl+A`，输入框内仍保留文字全选 |
| 对齐与等距 | 多选后用「整理选中节点」；等距排列至少留 32 个画布单位的间隔 |
| 回到选中 | 工具栏「居中」，多选时按整组选区居中 |
| 看全图 | 「适配」；大画布也可按需打开「小地图」，点击或拖动跳转 |
| 搜索 | `⌘F` / `Ctrl+F`，按标题、镜头号和台词定位 |
| 删除 | 卡片上的 ×、右键删除、多选工具条或 `Delete` / `Backspace` |
| 撤销 / 重做 | `⌘Z` / `Ctrl+Z`；`⇧⌘Z` / `Ctrl+Shift+Z` |

删除节点只移除画布里的卡和连线，不删除素材文件。批量整理、复制和删除各算一步撤销。小地图默认收起，需要时打开，关闭后不占创作区。

## 做短剧

「新建短剧工作流」按剧本、角色、场景、分镜和最终剪辑组织工作。角色可绑定音色，镜头可标明说话人。先确认剧本和分镜草稿，再生成需要的首帧、视频和配音。

制片进度指出缺少哪些素材；一键补齐受并发上限控制。部分失败后只重试失败项。已经生成的版本可在节点设置里查看和切换，修改一个镜头无需重新生成整部作品。

生成前请核对模型、提示词和参考素材。接口计费由你配置的服务决定；没有报价的数据会明确显示未知。

## 出错与恢复

- **空提示词**：焦点回到要填写的位置；不会用默认文案或上游描述代替指令生成。
- **断线、刷新后没拿到结果**：卡上会保留待收取任务。先点「看结果」；只有明确想再付费生成时才选「再生成一次」。
- **生成失败**：保留错误原因和已有结果；批量生成可以只重试失败项。
- **误删节点**：立即撤销，节点与连线一起回来。误删整张画布可从画布下拉框的回收站恢复。
- **多处同时编辑**：同步按节点合并。遇到双方修改同一内容时显示冲突选择，不静默覆盖。
- **保存失败**：保留本机副本并提示重试。切换项目或画布前先提交尚未保存的改动。

## 性能与维护

前端继续使用 JointJS 和项目原有的普通 JavaScript 脚本，不额外引入另一套界面框架。

| 改动 | 维护位置 |
| --- | --- |
| 节点定义、空初值、旧字段兼容 | `public/js/app-07-canvas-state.js` |
| 视口定位、滚轮合帧、小地图、多选整理 | `public/js/app-07-canvas-viewport.js` |
| 卡片、右键、复制、删除、撤销 | `public/js/app-07-canvas-nodes.js` |
| 增量同步、存盘、冲突与恢复 | `public/js/app-07-canvas-board.js` |
| 生成校验、任务回收、结果记录 | `public/js/app-07-canvas-generate.js` |
| 卡内输入、检查器、分镜展开 | `public/js/app-07-canvas-inspector.js` |
| 页面创建、事件绑定与销毁 | `public/js/app-07-canvas.js` |

开发时保持以下约束：

- 轮询同步仅更新实际变化的卡片；无变化的卡保留 DOM 和媒体播放器。
- 一帧内的滚轮事件累计后只更新一次 SVG 变换，保留光标锚点和全部位移。
- 卡内连续输入先更新节点数据，短暂合并后存盘；失焦、切换和离开页面前立即保存最后一笔。
- 用户批量操作用 `canvas-edit` 批次抑制重复存盘，不能用 `bulk` 跳过角色关系回写。
- 添加/恢复节点时，显式传入的位置必须保留；恢复存档不能抢走用户输入焦点。
- 新增定时器、动画帧、观察器和全局监听时，同时补上页面销毁清理。

回归入口：`node test/all.js --only canvas,canvas-store`。其中画布测试在隔离的 Chromium 中运行，覆盖实际 DOM、输入、连线、保存与撤销；160 节点场景检查单卡更新仅重绘一张，滚轮合帧检查累计位移。它们不是所有设备上的帧率保证，实际表现仍受节点数量、媒体大小和硬件影响。
