## OAuth 状态流 / OAuth flow

1. 已登录的平台管理员调用 `POST /api/mcp/oauth/start`；回调必须返回当前工作台。Authorization URL、一次性 flow ID、过期时间返回前端，不返回令牌。
2. 外部浏览器访问服务商授权页。公开回调 `/api/mcp/oauth/callback` 只暂存与 state 绑定的授权码，不兑换、不回显输入。
3. 发起账号通过 `POST /api/mcp/oauth/finish` 兑换；验证账号、有效期、issuer、PKCE 和连接器地址。成功后仅重连这一台连接器。
4. `cancel` 撤销未完成的流程；`remove` 删除本机凭据并停止连接器。刷新或兑换中移除授权，旧响应也不能恢复凭据。

The external browser does not need the desktop application's login cookie. The authenticated initiating account performs the exchange. Refresh requests are deduplicated, rotated tokens are persisted, and pending revocation prevents credential resurrection. Removing local authorization does not revoke the provider-side grant.

Native OAuth is for Streamable HTTP with the built-in engine. Legacy stdio helpers keep their own authorization. Do not claim every provider was tested against a real account: automated tests use isolated local authorization servers and no user credentials.

## 审查接口 / Review API

- `GET /api/session/:id/checkpoints/:checkpoint/review`：返回 UTF-8 文件的改动块、行号、版本哈希与冲突状态。
- `POST /api/session/:id/checkpoints/:checkpoint/revert`：提交 `hunk` 与当前 `hash`。任务必须属于本人且已停止。重复选择同一块为撤销回退。
- 快照缺失、哈希不符、非 UTF-8、二进制、超过 1 MiB 或 20,000 行、路径逃逸时拒绝操作。CRLF 与末尾换行按字节保留。

Region and line annotations enter an editable composer draft. They instruct the Agent to preserve unrelated content and ask on ambiguity. They are location hints, not a deterministic editing sandbox; verify the resulting file. The sandboxed preview never receives application cookies or API privileges.

## 团队费用 / Team costs

发送第一条消息前设置 `billing_scope: "team"` 或 `"personal"`。已有记录的任务不能改归属；个人 Key、未共享渠道和个人订阅引擎不能用于团队任务。由任务创建的排期保留费用归属。`GET /api/my-task-costs` 只汇总当前账号、当前组织、本月的模型与付费工具记录。

Both scopes remain subject to existing organization and member limits. Prices are estimates from the configured price table. Unknown prices are reported separately, and upstream bills are authoritative. No billing report may infer a zero cost from a missing price.

## 测试与发布 / Verification and release

```bash
npm ci
node test/all.js --only mcp-oauth,oauth-api,oauth-ui,mcp-policy
node test/all.js --only checkpoint-review,review-ui,task-billing,team-task-api
node test/all.js --only chrome-link,chrome-ext,browser-recording,ui-language
npm test
```

所有测试使用临时数据目录；浏览器测试使用隔离的配置和隐藏窗口。新增界面进入英文后调用 `I18N.untranslated` 并对非空结果报错，另加故意漏翻的反向用例，避免检查形同虚设。

Use temporary homes, fake credentials and local service fixtures. Never pair a developer's real browser, authorize a real account or make paid model calls merely to run regression tests. Before a release, inspect the exact pending diff and metadata for secrets, local paths and personal identity, then verify the package contents and installer pipeline.
